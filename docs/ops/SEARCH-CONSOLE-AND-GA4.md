# Google Search Console and GA4 (owner checklist, £0)

Both are owner-account actions in the open Chrome browser. The application already contains everything they need.

## Search Console (do this the day production goes live)

1. https://search.google.com/search-console → Add property → **Domain** property `studymedicineuknigeria.com` (covers http/https and the staging subdomain; staging is `noindex` and basic-auth protected, so it will never appear).
2. Verify by **DNS TXT record** in hPanel → Domains → DNS: add the `google-site-verification=…` TXT at `@`. Propagation is usually minutes.
3. Sitemaps → submit `https://studymedicineuknigeria.com/sitemap.xml` (generated by the app; only published, indexable pages are listed; gated pages join automatically once their facts are verified).
4. Settings → Users: add `info@studymedicineuknigeria.com` as owner if the property was created with another account.
5. Monthly: Performance → filter Country = Nigeria → export Queries and Pages as CSV into `data/gsc/queries-YYYY-MM.csv`. Research 02 and the asset register are updated from that export (the research loop in `docs/decision/00-DECISION-REPORT.md`).

What to expect at first: zero impressions for the first days, then branded queries; non-branded Nigerian queries build over weeks. Do not react to day-level noise.

## GA4 (only if you want third-party analytics at all)

The first-party funnel (Admin → Funnel) already measures every step without cookies. GA4 adds acquisition sources and device data at the cost of a consent banner on the public site.

1. https://analytics.google.com → Admin → Create property "Study Medicine UK Nigeria", reporting time zone Africa/Lagos, currency GBP.
2. Data stream → Web → `https://studymedicineuknigeria.com`. Copy the **Measurement ID** (`G-…`). Turn **Enhanced measurement** off except Page views (we send our own events).
3. Data settings → Data retention → 14 months. Data collection → do **not** enable Google signals (the site passes `allow_google_signals: false` anyway).
4. Put the Measurement ID in the server `.env` as `SITE_GA4_ID=G-…` (via the bootstrap workflow variable, or edit `~/apps/smukn-production/shared/.env` and run `php artisan config:cache` in `current/`). Nothing loads until the visitor accepts the banner.
5. Events the site sends after consent: `course_viewed`, `apply_viewed`, `apply_click` (with `location`), `eligibility_started`, `lead_created`, `account_created`. Mark `lead_created` and `account_created` as key events in GA4 → Admin → Events.
6. Link Search Console to GA4 (Admin → Product links) for query data inside GA4.

Leave `SITE_GA4_ID` blank to run without any third-party analytics; the site is complete without it.

### Owner routine (about 10 minutes, Search Console has no free API access configured here)

- **Week 1:** URL inspection → *Request indexing* for the five priority pages: `/`, `/study-medicine-in-the-uk/from-nigeria`,
  `/requirements/waec`, `/medical-schools`, `/fees`. Do not request the other 23 by hand; the sitemap covers them.
- **Weekly for 6 weeks, then monthly:** Indexing → Pages: record *Indexed* and *Not indexed* counts and the reasons in
  `data/gsc/pages-YYYY-MM-DD.csv` (columns `date,indexed,not_indexed,reason,count`). Expected and harmless reasons:
  *Page with redirect* (legacy URLs, www), *Excluded by noindex* (university pages, portal), *Not found (404)* (the gone list).
  Act on *Server error (5xx)*, *Duplicate without user-selected canonical*, *Crawled – currently not indexed* for a
  sitemap URL after 6 weeks (upgrade that page's content before adding any new page; `docs/seo/DECISION-ENGINE.md`).
- **Monthly:** Performance → Country = Nigeria → export Queries and Pages (step 5 above).
- **Never** count a page as indexed until the Pages report or URL inspection says *URL is on Google*.
